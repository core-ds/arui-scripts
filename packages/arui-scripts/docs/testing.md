# Тесты и покрытие arui-scripts

## Запуск

Из корня репозитория:

```sh
yarn install --immutable
yarn build
yarn workspace arui-scripts test:coverage
```

HTML: `packages/arui-scripts/coverage/index.html`. Машинные отчёты: `coverage-summary.json`, `coverage-final.json`, `lcov.info`.

Jest учитывает все JS/TS-файлы в `src`, включая не импортированные тестами. Исключены только тесты и декларации типов. Минимальный общий порог по каждому из четырёх показателей — 80%. Это порог для пакета `arui-scripts`, а не для каждого файла или всей монорепы.

| Functions     | 29,08% | 82,49% |
| Lines         | 37,94% | 82,12% |
| Тесты         |     47 |    269 |
| Наборы тестов |     17 |     52 |

Добавлены проверки:

-   Загрузка и объединение конфигурации, ошибки чтения, вычисление путей и параметров словарного сжатия.
-   Пресеты Jest и Vitest: трансформеры, aliases, setup-файлы, CSS и статические ресурсы.
-   Конфигурация dev-server, Module Federation, обработка assets и параметры оптимизации изображений.
-   CSS-плагины: префиксы, глобальные переменные, зависимости темы и повторное использование процессора.
-   Хуки компилятора, перезапуск сервера, runtime CSS в браузере и при SSR.
-   CLI: выбор команд, аргументы дочерних процессов, коды завершения, сообщения об ошибках и предупреждения CI.
-   Генерация env-конфига, legacy API и преобразование настроек artifacts.

Файловые сценарии используют временные каталоги с очисткой. Компилятор, Docker и дочерние процессы подменяются на границах взаимодействия: эти тесты не запускают реальные серверы или контейнеры.

## Что остаётся за пределами юнит-тестов

Общее покрытие не означает, что каждая команда проверена полностью. Приоритет для следующего этапа:

-   Полный запуск dev-server, HMR и восстановление после ошибок компиляции.
-   Сборка итоговых клиентских/серверных Rspack-конфигураций в разных режимах.
-   Команды анализа bundle и changelog, запуск Jest с пользовательской конфигурацией.
-   CLI artifacts и подготовка Docker-файлов через совместимый API.

Для сквозной проверки в репозитории остаётся `yarn test`: сборка пакетов и приложений-примеров, тесты и валидация результатов. Юнит-тесты дополняют эту проверку.
