**Что изменилось**
Добавлена диагностика persistent cache для проверки локально и в Jenkins: настройки каждого компилятора, подтвержденное восстановление snapshot, инвалидация, счетчики сжатия и завершение закрытия компилятора. Значения переменных окружения не выводятся.

**Что делать потребителю**
При включенном `persistentCache` задайте `ARUI_SCRIPTS_CACHE_DEBUG=1` на время проверки. Сравните холодную и повторную сборки по событиям с префиксом `[arui-scripts cache]`. Без переменной дополнительный лог выключен.
