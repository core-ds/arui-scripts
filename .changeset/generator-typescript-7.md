Новые проекты используют TypeScript 7 и Yarn 4.18.0. Из выбора транспилятора удален
`tsc`, а зависимость `ts-jest` больше не добавляется: код преобразуют SWC или Babel.
Для проверки типов приложения и тестов добавлена команда `typecheck`.

При подключении линтера отдельная копия TypeScript 6 изолирована через Yarn
`packageExtensions` или npm `overrides`; компилятор приложения остается на TypeScript 7.
Для установки с npm используйте npm 10.9.3 или новее.
