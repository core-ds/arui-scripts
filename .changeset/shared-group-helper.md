**Что изменилось**
Добавлен helper `createSharedGroup` из `arui-scripts/helpers` для настройки Module Federation: библиотеки компонентов могут переиспользоваться при совпадении точных установленных версий runtime-зависимостей, например `react` и `react-dom`. При несовпадении runtime или несовместимой версии библиотеки используются локальные fallback-копии. Поддерживаются отдельные импорты, префиксы импортов и синхронный вход хоста с `eager: true`.

**Что делать потребителю**
Для использования импортируйте `createSharedGroup` из `arui-scripts/helpers` и передайте его результат в `modules.shared` у хоста и модуля. Укажите абсолютный путь к `package.json` приложения, одинаковый список `runtime` и нужные `libraries`; для синхронного хоста задайте `eager: true`, для асинхронного модуля — `eager: false`. Не переопределяйте сгенерированные правила runtime обычными shared-настройками. Если helper не нужен, менять существующую конфигурацию не требуется.
